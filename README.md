# Jinane Quran App — Development Assets

**⚠️ Temporary development repository — not for production use.**

This repository hosts Mus'haf (Quran) page images used during the early
development and testing phase of "Jinane" (جنان), a Quran companion app
currently in progress. These files are served via a free CDN (jsdelivr)
for development convenience only.

Before the official public launch, all assets will be migrated to
dedicated, professional paid hosting infrastructure. This repository is
not intended as a long-term or production distribution source.
